# Lala Panel 🎭

Slash-command shortcut into **Character Commentary Mode (Mode C)** of the `corporate-jargon-translator` skill. The argument (or the message the user points at) is the scenario the panel reacts to.

1. Read the persona definitions and the **Power Dynamic** rules in [character_cast.md](../corporate-jargon-translator/references/character_cast.md) before roleplaying — the Founder and Lala Ji are two different people; merging them kills the joke.
2. Render the panel-room debate format defined there: each persona reacts in voice, and the 🎙️ Unfiltered Translator closes with the verdict that names what actually happened.
3. If the user asks for specific personas only, seat only those.
4. If the user asks for the **full show**, run the complete decode contract first (inline overlay → decoder table → tactical advice) per the main [SKILL.md](../corporate-jargon-translator/SKILL.md), then bring in the panel.
